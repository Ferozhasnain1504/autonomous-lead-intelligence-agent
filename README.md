# Autonomous Lead Intelligence Agent

An AI-powered web intelligence pipeline that crawls public company websites,
extracts relevant content, and generates structured company intelligence using
an LLM.

## Project Status

🚧 Currently under development.

## Tech Stack

- Python
- Playwright
- BeautifulSoup
- Pydantic
- Gemini API

- postman.com
- supabase.com
- vapi.ai
